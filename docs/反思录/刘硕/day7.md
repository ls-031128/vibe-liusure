\# 第 7 天反思



\## 今天指挥 AI 干成了什么



今天完成了宠物健康平台的 AI 能力集成。



通过 DeepSeek API 接入 AI 健康助手，实现用户输入宠物健康问题后，结合宠物信息和健康评估数据生成建议。



同时完成了 AI 成本估算文档、数据库字典和冲刺任务板。





\## 卡过什么坑、怎么爬出来的



主要问题是 AI 接入时需要处理 API Key 安全、数据库上下文传递和运行环境配置。



解决方式：



让 AI 将 Key 放在服务端环境变量中，通过后端接口调用模型，不让前端直接暴露。





\## 对话证据



提问：



如何给宠物健康平台接入 LLM 能力？



AI建议：



使用后端接口封装 DeepSeek API，将宠物信息和健康评估记录组成结构化 prompt，再返回 AI 建议。



修正：



增加失败兜底、环境变量隔离和测试。





\## 明天改进的一个动作



完成公网部署验收，让教师手机可以访问线上版本，并验证真实数据展示。
