# 宠物健康平台 Day 4 T2 部署手册

> 状态：部署准备中。Neon/Vercel 账号、云数据库、公网地址和真实线上读写均待执行；本文不是部署成功证明。

## 目标架构

- Next.js App Router 部署目标：Vercel Hobby（待网页端创建项目并确认账号条款）。
- PostgreSQL 托管目标：Neon Free（待网页端创建数据库）。
- Vercel Functions 运行宠物与健康评估 API；应用运行时使用 Neon pooled PostgreSQL URL。
- Prisma 7.10.0 CLI 迁移使用 Neon direct PostgreSQL URL。

## 环境变量

配置以下变量，不要把真实值写入代码、README 或 `.env.example`：

| 变量 | 用途 | 配置位置 |
|---|---|---|
| `DATABASE_URL` | 应用运行时 PostgreSQL 连接，使用 Neon 提供的 pooled URL | 本地 `.env`；Vercel 环境变量 |
| `DIRECT_URL` | Prisma CLI migration 使用的 direct URL | 本地 `.env`；需要迁移的环境 |
| `TEST_DATABASE_URL` | API 集成测试使用的独立、非生产 PostgreSQL 分支 URL | 仅本地/测试环境，不配置为生产库 |

`.env.example` 中只包含连接格式占位符。Neon URL、分支、SSL 参数以 Neon 控制台当前生成的连接信息为准。Vercel Preview 与 Production 应分别绑定对应环境的连接值。

## Prisma 命令

在 `pet-health-platform` 目录安装锁文件依赖、校验 schema 并生成 client：

```bash
npm ci
npm run db:validate
npm run db:generate
```

确认 `DIRECT_URL` 指向已批准的空 PostgreSQL 数据库后，应用 PostgreSQL migration：

```bash
npm run db:migrate:deploy
```

此初始化只创建 `pets`、`health_assessments` 表、外键及索引；不读取或导入 SQLite 记录。不要对生产数据库运行 `prisma migrate dev`，也不要使用 `db push` 替代已版本控制的 migration。

## SQLite 数据归档

原 `prisma/dev.db` 保留为本地归档；SQLite migration 历史保留在 `prisma/migrations/`，历史 SQL 参考保留为 `db/schema.sqlite.sql`。新线上 PostgreSQL schema 使用 `prisma/schema.prisma` 和 `prisma/migrations-postgresql/`。本次决定为从空数据库开始，不迁移任何 SQLite 记录。

不要删除、覆盖或重新初始化本地 `prisma/dev.db`。它被 `.gitignore` 排除，不应提交到仓库。

## Vercel 配置（待执行）

1. 在网页端创建/登录 Vercel Hobby 账号，并确认课程个人项目符合当前计划条款。
2. 连接经确认支持的 Git 来源，或另行确认 CLI 部署方式；当前分支的代码尚有未提交修改，本手册不代表这些修改已提交或上传。
3. 将 Project Root Directory 设为 `pet-health-platform`。
4. 使用 `npm ci` 安装依赖，Build Command 使用 `npm run build`。Next.js 的运行和 API 路由由 Vercel 管理，不设置自建服务器启动命令。
5. 在 Vercel 环境变量中分别配置 `DATABASE_URL`、`DIRECT_URL`，按 Preview/Production 环境选择 Neon 连接目标。
6. 确认环境变量后，先应用 PostgreSQL migration，再部署应用。
7. 记录实际生成的 HTTPS 公网 URL。当前没有公网 URL，页面、API 和数据持久化都尚未在线验证。

Neon 的账号注册条件、连接变量形式、免费额度是否适用当前账号，以及 Vercel Hobby 的账号资格和用量限制，均需在网页端创建账号时再次确认。不要在未确认的情况下启用付费方案或添加付款资源。

- 当前未创建 Neon 数据库，也未配置自动备份；此能力待执行和核对。

- 本 MVP 没有登录/授权；公网测试只使用虚构宠物与演示评估数据，不录入真实用户身份或健康文本。
