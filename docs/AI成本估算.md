# AI 成本估算

估算日期：2026-10-13。本文用于课程实验预算，用户量、调用次数和平均 token 数均为假设，不代表实际运营数据或账单。

## 1. 功能说明与调用场景

| 项目 | 说明 |
| --- | --- |
| 功能 | AI 宠物健康助手 |
| 使用场景 | 主人选择已有宠物，输入健康或日常护理问题，获得结合宠物资料及近期观察记录的建议 |
| 调用入口 | 前端提交问题后，由服务端 `POST /api/ai/pet-advice` 调用 DeepSeek Chat Completions |
| 输入上下文 | 安全提示词、宠物名称/年龄/物种、最近风险标签、最近 5 条用户手动评估摘要、用户问题；未记录的品种明确标为“未记录” |
| 输出 | 日常护理建议、观察信息和咨询兽医提醒，不进行疾病诊断或提供处方、药物剂量 |
| 触发频次 | 按每次有效提交触发一次 API 调用估算；浏览页面、切换宠物或查看历史本身不触发 AI 调用 |

## 2. 模型与价格口径

本次按要求将 `deepseek-chat` 作为计划估算的模型标识。现有代码默认值为 `deepseek-flash`，实际调用由服务端 `AI_MODEL` 决定；本文件不修改项目配置。

截至本次查询，[DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)列出了 `deepseek-flash` 和 `deepseek-v4-pro`，未单列 `deepseek-chat`。因此，`deepseek-chat` 的可用性、实际模型映射及当前价格需要根据官方信息再次确认，不采用历史价格作为现价，也不把 Flash 单价视为 Chat 单价。

| 模型/计费情况 | 输入单价（元/百万 tokens） | 输出单价（元/百万 tokens） | 使用方式 |
| --- | ---: | ---: | --- |
| `deepseek-chat` | 待官方确认，记为 P入 | 待官方确认，记为 P出 | 主估算使用公式，核实后代入 |
| `deepseek-flash`，空闲时段，输入缓存未命中 | 1 | 4 | 仅供现有项目配置的参考计算 |
| `deepseek-flash`，高峰时段，输入缓存未命中 | 2 | 8 | 仅供现有项目配置的参考计算 |

上述 Flash 价格来自本次查询的[官方价格表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，价格可能调整，实际费用以调用时官方价格和账单为准。本文不假设缓存命中或赠送余额；高峰/空闲时段按官方规则划分，并非本项目自行定义。

## 4. 单次输入 token 拆分

| 输入组成 | 假设平均 tokens |
| --- | ---: |
| 系统角色与健康安全提示 | 400 |
| 宠物资料及最近风险标签 | 100 |
| 最近评估摘要 | 700 |
| 用户问题 | 200 |
| 结构化字段、格式及消息开销 | 100 |

这些是预算占位估计，尚未使用模型 tokenizer 或真实响应测量。token 不等于中文字符数；问题和历史摘要较长时，实际输入可能显著超过平均值。当前每次请求只携带近期记录和本次问题，没有追加连续聊天的完整对话历史。

| 场景 | 每日用户数 | 每人每日调用 | 每日调用 | 月调用（30 天） | 月输入 tokens | 月输出 tokens | 月总 tokens |

| 月输出 | 3,000 × 500 = 1,500,000 tokens |
| 月总量 | 4,500,000 + 1,500,000 = 6,000,000 tokens |

## 6. 月度 API 成本

无缓存命中时：月成本（元）= 月输入 tokens ÷ 1,000,000 × P入 + 月输出 tokens ÷ 1,000,000 × P出。输入与输出分别计费，不能直接用总 tokens 乘单一价格。

| 场景 | `deepseek-chat` 月成本（价格待确认） | Flash 全部空闲时段参考（元/月） | Flash 全部高峰时段参考（元/月） |
| --- | --- | ---: | ---: |
| 小规模试用 | 0.45 × P入 + 0.15 × P出 | 1.05 | 2.10 |
| 课程演示主方案 | 4.5 × P入 + 1.5 × P出 | 10.50 | 21.00 |
| 扩大试用 | 27 × P入 + 9 × P出 | 63.00 | 126.00 |

主方案的 Flash 参考计算：空闲时段为 4.5 × 1 + 1.5 × 4 = 10.50 元；高峰时段为 4.5 × 2 + 1.5 × 8 = 21.00 元。两列表示相同假设用量下的时段价格情景，不是实际账单或最高费用保证；`deepseek-chat` 的月成本仍需填入其已核实单价后计算。

## 7. 估算范围与后续校准

| 项目 | 对费用的影响/处理 |
| --- | --- |
| 缓存命中 | 可能降低输入费用，本次按全部未命中估算；实际应分别统计命中和未命中 token |
| 长问题或长历史 | 增加输入 token，不能把 1,500 当成输入上限 |
| 用户重复提交、开发验证或失败调用 | 未计入基础方案；发生费用时以平台实际 usage 和账单追加统计，不能默认全部失败请求免费 |
| 云托管、数据库、域名 | 本文仅计算 AI API 费用，不包含这些费用 |
| 实际用量统计 | 后续可根据响应中的 `usage` 和官方账单校准平均输入/输出；当前代码未保存这些统计，不声称已有实测数据 |
| 模型/价格变化 | 核对 `AI_MODEL` 对应模型后，按官方最新价格重算；若使用 `deepseek-chat`，先确认其当前可用性与单价 |

课程报告可引用“主方案每月约 600 万 tokens”作为假设结果；精确金额应注明模型、价格查询日期、缓存及调用时段口径，并根据官方价格调整。
