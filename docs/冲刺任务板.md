## 剩余风险

- AI 建议不能替代兽医诊断：模型可能错误或遗漏；持续保留不确定性说明、护理建议边界和咨询兽医提醒。
- LLM 调用成本控制：目前没有用户配额控制；结合 `AI成本估算.md` 和实际 usage 校准用量，核对实际模型单价并控制重复调用。
- 数据安全：保护服务端 Key 和数据库凭据，避免日志泄露；确认此前暴露的数据库凭据已完成轮换，控制发送给第三方的上下文并准备备份恢复措施。
- 部署环境稳定性：核验运行时配置、数据库连接、构建与启动过程；线上可访问和数据持久化必须通过实际验收确认。

## 后续计划

- 用户系统：根据真实使用反馈评估登录、访问权限和不同用户的数据隔离需求。
- 宠物长期健康档案：在当前录入与记录闭环稳定后，评估长期信息整理和历史追踪功能。
- 商业化探索：先验证用户需求、使用频次与服务成本，再探索可持续模式，保持宠物健康信息辅助定位。

以上后续计划不作为当前冲刺的必交付功能，不提前扩张 MVP 范围。
