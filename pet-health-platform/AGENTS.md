# AGENTS.md

## 项目目标

本项目是“宠物健康信息辅助 MVP”，帮助普通宠物主人整理宠物基本信息和当前症状，获得初步风险提示、观察建议和就医提醒。

## 当前 MVP 边界

- 当前处于课程 MVP 阶段，Day 3 已确定使用 SQLite + Prisma 作为本地数据库基础设施。
- 当前已落地数据库配置、最小数据模型和宠物基本信息录入闭环，不实现健康评估 API 或列表页面。
- 后续健康评估功能必须服务于信息整理和初步风险提示。
- 不为了生产级扩展引入 PostgreSQL，也不提前加入登录、健康档案、社区、商城或在线问诊。
- 数据库只保存当前闭环所需的最小必要数据。
- 当前不保存用户原始健康文本，不保存用户身份信息，也不做疾病诊断数据存储。

## 宠物健康安全约束

- 不做疾病诊断，不把 `riskLevel` 表述为医学风险评分或确诊结论。
- 不提供处方、药物剂量或自我治疗方案。
- AI 输出必须明确说明不确定性，不得把用户未提供的信息当作事实。
- 对高风险情况明确建议咨询或就诊兽医。
- 不得凭空编造医学规则、阈值、疾病映射或事实。
- 不在代码中加入未经验证的关键词诊断规则。

## 修改与验证要求

- 修改代码前先理解现有目录结构和文件职责。
- 优先进行小步修改，每次只解决当前已确认的问题。
- 修改后运行相关测试；涉及构建或类型的修改还要运行对应检查。
- 不要把 AI 的生成结果或口头说明当作验证结果，必须检查文件、命令输出和实际运行行为。
- 不得修改 `vibe-lab1/` 第一日项目。
- 不得提交 `node_modules/`、`.next/`、`tsconfig.tsbuildinfo` 等依赖或构建产物。
